# Hermes 화면 스펙 v0.1 (초안)

> 2026-11-27 · 기준: Mnemo 화면 구성(`ggontee/mnemo-app`의 SwipeCard, CardStack, ArticleCard, ArticleDetail, KeptList, CommentModal). 카드 바깥(스택, 스와이프, 보관함)은 Mnemo와 같고, 카드 안쪽만 유형별로 다르게 그린다.

## 1. 화면 목록

| 경로 | 화면 | Mnemo 대응 |
|---|---|---|
| `/` | 피드: 카드 스택 | `page.tsx` + `CardStack` |
| `/card/[id]` | 카드 상세 | `ArticleDetail` |
| `/kept` | 보관함 | `kept/page.tsx` + `KeptList` |
| `/kept/[id]/analysis` | 심화 분석 결과 | `OutputGenerator`(일부) |
| `/status` | 상태: 마지막 수집, 오늘 상한, 소스 오류 | 없음 (새로 만듦) |

하단 내비게이션: 피드 · 보관함 · 상태. 상단: 필터 칩.

## 2. 피드 (공통)

- 카드 한 장씩. **오른쪽 스와이프 = 보관, 왼쪽 = 버림.** Mnemo의 `SWIPE_THRESHOLD = 120`, 회전·투명도 효과를 그대로 쓴다.
- 보관 직후 한 줄 코멘트 입력(`CommentModal`). 건너뛸 수 있다.
- 되돌리기: 마지막 한 장은 화면 하단 "되돌리기" 버튼으로 복구 (5초).
- 카드를 누르면 상세로 간다. 카드 안 스크롤은 Mnemo처럼 가로 스와이프와 충돌하지 않게 처리한다.
- **필터 칩:** 분야(전체 / AI / Tech / Bio), 유형(전체 / SNS / 글 / 영상), 인물(검색). 선택은 기기에 기억한다.
- **정렬:** 최신순. (3단계에서 반응 기반 가중치)
- **빈 화면:** "새 카드가 없습니다. 다음 수집: 14:00" 처럼 다음 실행 시각을 보여 준다.

### 카드 머리 (세 유형 공통)

```
[SNS]  AI · Simon Willison · Datasette            3시간 전
```
- 유형 배지 색: SNS 하늘색, 글 보라색, 영상 빨간색 (다크 모드 대응).
- 인물 아바타(있으면), 이름, 소속 한 줄, 상대 시간(24시간 넘으면 날짜).
- 묶인 카드(dev-spec 5장)면 오른쪽에 `+1 채널` 표시.

## 3. 유형별 카드

### 3.1 짧은 SNS (`short`)

```
┌─────────────────────────────┐
│ [SNS] AI · 이름 · 소속   시간 │
│                             │
│ 번역 본문 (전문)             │
│  링크·멘션·해시태그·코드 그대로 │
│                             │
│ [이미지 1~4장 그리드]          │
│                             │
│ ▸ 원문 보기  (누르면 펼침)     │
└─────────────────────────────┘
```
- 본문 글자 크기는 긴 글 요약보다 한 단계 크게. 짧으니 한눈에.
- 원문 보기는 카드 안에서 펼친다(상세로 가지 않음).

### 3.2 긴 글 (`long`)

```
┌─────────────────────────────┐
│ [글] Tech · 이름 · 매체   시간 │
│                             │
│ 한국어 제목 (굵게, 2줄까지)     │
│                             │
│ • 요약 1                    │
│ • 요약 2                    │
│ • 요약 3                    │
│                             │
│ 왜 중요한가: so_what 한두 줄   │
│                             │
│ #태그 #태그 #태그              │
│ 💬 작성자 한마디 (묶인 SNS 글)  │
└─────────────────────────────┘
```
- Mnemo `ArticleCard`와 같은 배치. 유료 글이라 앞부분만 받았으면 "미리보기만 수집됨" 표시.

**상세:** 탭 [요약] [전문 번역] [원문]
- 전문 번역 탭: 문단 단위. 기본은 번역만, "원문과 나란히" 토글을 켜면 문단마다 원문(회색)이 아래에 붙는다(폰 폭이라 좌우가 아니라 위아래).
- 원문 탭: 원문 링크 버튼 + 수집한 원문 텍스트.

### 3.3 영상 (`video`)

```
┌─────────────────────────────┐
│ [영상] AI · 채널          시간 │
│ [썸네일 16:9]       ▶ 1:12:30 │
│                             │
│ 한 줄 요약 (굵게)              │
│                             │
│ 03:12  구간 제목 — 한 줄       │
│ 18:40  구간 제목 — 한 줄       │
│ 41:05  구간 제목 — 한 줄       │
└─────────────────────────────┘
```
- 카드에는 구간 3개만(중요도 순), 상세에 전체 5~8개.
- 받아쓰기에 실패해 제목·설명만으로 요약한 경우 "설명 기반 요약" 표시.

**상세:**
- 위: YouTube 임베드 플레이어 (`youtube-nocookie.com`).
- 구간 목록: 누르면 플레이어가 그 시점으로 이동(IFrame API `seekTo`).
- 아래: 스크립트 번역 (타임스탬프 단락, 접힘 기본).

## 4. 보관함

- 목록: 최신 보관순. 각 줄에 유형 배지, 제목(SNS는 본문 첫 줄), 인물, 코멘트, 태그.
- 필터: 분야, 유형, 태그(`TagCloud`), 심화 분석 여부.
- 항목 메뉴: 코멘트 수정, 태그 추가/삭제, 보관 취소, **[심화 분석]**.
- **[심화 분석]** 누르면: 확인 시트("Claude로 분석해 Tana #Research에 저장합니다. 예상 비용 약 $x") → 대기열에 넣음 → 상태 배지 `대기 → 분석 중 → 완료 / 실패`. 완료되면 "Tana에서 열기" 링크.
- 하루 분석 상한에 닿으면 버튼이 비활성화되고 이유를 보여 준다.

## 5. 심화 분석 결과 화면

- Markdown 렌더(`MarkdownRenderer` 재사용).
- 위에 메타: 원 카드 링크, 생성 시각, 비용, Tana 저장 상태.
- [다시 분석] (질문을 한 줄 덧붙여서), [Tana에서 열기].

## 6. 상태 화면

- 마지막 수집 회차: 시각, 새 글 수, AI 처리 수, 상한 때문에 미룬 수, 오류 수.
- 오늘 사용량: 처리 건수 / 60, Claude 토큰, Gemini 영상 수, 추정 비용.
- 소스 오류 목록: 이름, 마지막 오류, 마지막 성공 시각.
- 다음 수집 시각.

## 7. PWA

- `manifest.webmanifest`: 이름 "Hermes", `display: standalone`, 세로 고정, 테마색.
- iOS용 `apple-touch-icon` 180px, 상태 표시줄 스타일.
- 서비스 워커: 앱 셸과 최근 카드 50장을 캐시해 지하철 등 오프라인에서도 넘겨 볼 수 있게. 스와이프 결과는 온라인이 되면 서버로 보낸다.
- 다크 모드: 시스템 설정을 따른다.
